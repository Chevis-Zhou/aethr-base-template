# The edit backend is a cross-repo contract

`src/lib/edit/` here is the SSOT; `aethr-portal/src/template/` is a **gitignored mirror**
(`aethr-portal/.gitignore:63`), wiped and regenerated by `aethr-portal/scripts/sync-template.mjs`
on every build. This is invisible from the code in either repo — a session already lost work in
2026-09 by hand-editing the portal's copy, since recovered. Consequence: `index.ts`'s exports are
a published contract across a repo boundary, and adding one is a commitment `aethr-portal` builds
against. Never hand-edit `aethr-portal/src/template/edit/` — edit here; `pnpm dev` in the portal
regenerates it.
