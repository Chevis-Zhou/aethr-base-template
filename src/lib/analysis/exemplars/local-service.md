# Register — local service

**Unexemplified. There is no eligible exemplar and the archetype ships anyway.**

**Fits:** local-service — cleaning, trades, landscaping, auto.
**Exemplars:** none.

---

`productized-voice.md` §6 records the reason. Chygo Property Care was the only local-service
delivery and it is **excluded by owner ruling** — it is not in the CMS and is never shown to
a client. Using a low-rated delivery as an exemplar is worse than having none, because an
exemplar is the thing generation imitates most directly.

Owner ruling: **ship the archetype anyway** and generate on the house register alone. The
archetype is a layout order and is unaffected; only the copy exemplar is missing.

A run that selects this register emits a flag — *"register unexemplified — generated on the
house register"* — so REVIEW knows the positive half of the copy system was absent for that
build. That is the whole mechanism; there is no fallback exemplar and substituting one from
a neighbouring register would be worse than the flag.

**This file closes when the first good local-service delivery ships.** Until then the row
stays empty and this paragraph stays here.
